What it does

Stop babysitting terminals.

Agents stall on a prompt you can't see. Vibe Notch puts every prompt in front of you and lets you answer in one click.

✅

Approve from anywhere

Deny, allow once, always allow or bypass — with Claude's own "always" rules offered as one-tap buttons. Risky commands get flagged.

±

Diffs you can actually read

Edits and new files show as a proper diff: file header, +/− counts and full-width tinted rows. Review before you approve.

❓

Answer questions in place

Multiple-choice and plan-review prompts from Claude and Codex appear in the notch. Pick an option, or type your own answer.

👻

Only the live agents

An exact count of agents running right now, waiting ones first. Finished sessions move to history, where you can resume them.

⏹

Interrupt & reply

Stop an agent's turn without killing it, or send "continue" from the row. Click a row to jump to that exact terminal tab.

🗂

Tray, music & calendar

Drag files onto the notch to park them, drag them back out anywhere. Now-playing controls and a week at a glance, built in.

Works with

One notch for every agent.

Hooks go in through each agent's own config — backed up first, and removed cleanly whenever you like.

Install

Download the app, or build it from source with one command.

It finds your agents

The setup guide detects the CLIs you have and wires their hooks, with a backup of every config.

Work as usual

Hover the notch when you want details. Prompts pop up on their own when an agent needs you.

# build from source (needs Xcode command line tools, macOS 14+)
git clone https://github.com/kaushal07wick/Vibe-Notch
cd Vibe-Notch
./scripts/bundle.sh release
open .build/VibeNotch.app
Questions

Good to know.

Do I need a MacBook with a notch?

It's designed around the notch, but on Macs without one it shows as a small floating pill at the top of the screen. Hover opens it just the same.

Is my code or data sent anywhere?

No. Agents talk to the app over a local Unix socket on your machine. There's no account, no server and no telemetry.

Will it change my agent configs?

It adds its own hook entries and backs up each config once before the first edit. "Disconnect all agents" in Settings removes only what it added.

Which agents are supported?

Claude Code and Codex have the deepest support: approvals, questions, diffs, history. Gemini CLI, OpenCode, Cursor and the Claude-schema forks (Qwen, Droid, Kimi) are wired through their hook systems and get the activity view.

Is it free?

Yes — open source under GPL-3.0. Star it on GitHub if it saves you a few terminal tabs.
